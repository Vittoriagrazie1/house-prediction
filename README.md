# House Price Predictor

A machine learning project that predicts house prices using Linear Regression built from scratch in pure Python.

## Features
- Linear Regression implemented from scratch (Normal Equation)
- Custom StandardScaler — no external libraries
- Tkinter GUI with sliders, dropdowns, and live prediction
- Feature importance visualization

## How to Run
```bash
python house_price_gui.py
```

## Requirements
- Python 3.x (tkinter is built-in — no installs needed)

## Tech Stack
- Pure Python (no numpy, no pandas, no sklearn)
- tkinter for GUI
- Linear Algebra from scratch (matrix inverse, OLS)

## Results
- R² Score: 0.99
- MAE: ~$9,500
